Role: Developer
The developer role is the primary code-producing agent. It receives a plan from the architect/planner and translates it into working code changes. Triggered by SingleIssueCycleWorkflow → ImplementActivity.
Action: Implement
Generates code changes for a single issue. Receives the plan, file list, and conventions. Expected output: a complete git-ready diff.
