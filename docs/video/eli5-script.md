# Tamma ELI5 Explainer Video Script

**Duration**: ~75 seconds (10 scenes)
**Audience**: Everyone -- no technical knowledge required
**Tone**: Simple, warm, slightly fun, confident
**Music**: Light upbeat lo-fi electronic

---

## Scene 1: The Pain

**Title**: "The Developer's Day"
**Duration**: 8 seconds
**Narration**:
> "Developers spend over half their day on work that isn't actually building features. Writing boilerplate. Fixing lint errors. Waiting for CI. Reviewing the same patterns again and again."

**Image Prompt**:
Digital illustration in a dark luminous tech-noir style, 16:9 aspect ratio. A simplified developer figure sitting at a desk surrounded by floating screens and notifications, looking overwhelmed. The screens show repetitive tasks: red error messages, spinning loading indicators, and long checklists. Color palette: muted grays and dull blues with coral red #EF4444 accents for the error states. Dark navy #0F0F1A background. Elements are slightly overlapping and chaotic, conveying clutter and fatigue. Subtle dot grid pattern in background. No photorealism, no bright white backgrounds.

**Transition**: Smooth fade (0.5s)

**Image Prompt**:
Digital illustration in a dark luminous tech-noir style, 16:9 aspect ratio. A flowing horizontal pipeline shown as connected glowing nodes from left to right. Each node is a rounded rectangle with an icon: (1) ticket/issue icon, (2) lightbulb/plan, (3) code brackets, (4) test beaker, (5) Git PR icon, (6) wrench/fix, (7) merge/checkmark. The nodes are connected by glowing purple #7B61FF lines with small animated-looking pulses traveling along them. A green #10b981 glow emanates from the final merge node. Dark navy #0F0F1A background. Clean, organized, flowing left to right. One small human figure silhouette at the start, pressing a button. No photorealism.
