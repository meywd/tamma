# Extra Keyframes for Long Scenes

Additional keyframe images planned for scenes lasting 7 seconds or longer. These supplement the existing "A" frame (already defined in the script files) with "B", "C", and "D" frames to maintain visual momentum and prevent static-feeling shots.

**Keyframe rules applied:**
- 5-6 sec: 1 image (A only)
- 7-8 sec: 2 images (A + B)
- 9-10 sec: 3 images (A + B + C)
- 11-12 sec: 3 images (A + B + C)
- 13-14 sec: 4 images (A + B + C + D)
- 15 sec: 4 images (A + B + C + D)
