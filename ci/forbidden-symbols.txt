# Story 29-10 — forbidden-symbols guard.
#
# Ripgrep patterns that fail the build if they appear in production
# code (apps/, packages/) outside of:
#   - EF migration files (Migrations/)
#   - test fixtures (tests/ and *.test.* / *.spec.*)
#   - markdown / documentation
#   - SystemSanitizationRules.cs — legitimate SAST regexes
#   - CredentialRedactor.cs + its test — Wave C.4 scrubbing utility;
#     same category as the SAST regexes (references prefixes to MATCH
#     and strip them, not because they're leaked).
#   - common-passwords.txt — password blocklist (contains 'changeme'
#     as a blocked value, not a real credential)
#   - init-fullstack.ts / config.ts — env-file templates that ship
#     placeholder values annotated with "xxx" / "_your_key_here"
#   - docker-compose.yml bootstrap defaults
#
# The ci/check-forbidden-symbols.sh wrapper applies the exclusion
# globs; keep this file focused on the patterns themselves.
